START WELL EDUCATION — GOOGLE SHEETS BACKEND (ALL WEBSITE DATA)
================================================================
Takes about 10 minutes. Do it once, signed in as startwelleducation@gmail.com.
Every tab and column is created AUTOMATICALLY — you never type headings.

WHAT GOES INTO THE SHEET
 Website -> Sheet (forms)
  • Contact Enquiries   every message from the Contact page   (ENQ-0001 …)
  • Admissions          every online application               (ADM-0001 …)
                        incl. STUDENT PHOTO (shown inside the sheet) and
                        B-FORM (link). Files are saved PRIVATELY in Google Drive:
                        Start Well Website Uploads / Admissions / ADM-0001 Name /
  • Email alert to startwelleducation@gmail.com for each one (Reply = answer parent)
  • "Status" drop-down: New / Contacted / In Progress / Admitted / Closed

 Sheet -> Website (content you edit in the sheet)
  • Gallery        photos on the Gallery page   (Preview column shows each photo)
  • News Ticker    the moving bar on the Home page
  • Holidays       the list on the School Calendar page
  These start filled with what the website shows today.
  Edit a row -> the website updates within seconds (refresh the page).
  "Show on Website" = No hides a row without deleting it.
  "Order" sets the order (1 first).

STEP 1 — Create the Google Sheet
  sheets.google.com -> Blank spreadsheet -> name it "Start Well Website Data"

STEP 2 — Add the script
  Extensions -> Apps Script -> delete everything in Code.gs ->
  paste ALL of google-apps-script/Code.gs -> Save (disk icon)

STEP 3 — Run setup once
  Choose function "setup" at the top -> Run.
  Allow permissions: Review permissions -> your account -> Advanced ->
  "Go to … (unsafe)" -> Allow. (Normal for your own script. It needs: this
  sheet, Gmail to send alerts, Drive to store uploads and gallery photos.)
  Back in the sheet you now have 5 tabs + a new menu "Start Well Website".
  Two Drive folders are created: "Start Well Website Uploads" (private)
  and "Start Well Website Gallery".
  Optional: run "testSubmission" to add sample rows, then delete them.

STEP 4 — Publish as a Web app
  Deploy -> New deployment -> gear icon -> Web app
    Execute as: Me        Who has access: Anyone
  Deploy -> COPY the Web app URL (https://script.google.com/macros/s/…/exec)
  Check: open the URL in a browser -> you should see {"ok":true, …}

STEP 5 — Put the URL in the website
  js/config.js ->  SHEETS_URL: 'https://script.google.com/macros/s/…/exec',
  Save -> upload/commit to GitHub -> Vercel publishes automatically.

STEP 6 — Test on the live site
  • Contact page: send a message.
  • Admissions -> Apply Online: attach a photo + B-Form and submit.
  • Change a headline in "News Ticker" -> refresh the Home page.

-----------------------------------------------------------------
ADDING GALLERY PHOTOS (easiest way)
  1. Upload photos into the Drive folder "Start Well Website Gallery".
  2. In the sheet: menu Start Well Website -> Add photos from Drive.
  3. Each new photo gets a row (title from the file name). Change Title /
     Category if you like. Done — it's on the website.
  Photos in that folder are made "Anyone with the link can view" so the
  website can show them. Admission uploads are NEVER made public.
  You can also paste any Google Drive photo link (shared "Anyone with the
  link") or a website path like images/photo.jpg into "Image Link".

GOOD TO KNOW
- If you EDIT the script after deploying: Deploy -> Manage deployments ->
  pencil -> Version: New version -> Deploy. (Keeps the SAME URL.)
- Menu "Set up / repair all tabs" re-creates any missing tab or column.
  It never deletes data. Renamed a column by mistake? Run it to restore.
- Turn off email alerts: Code.gs -> SEND_EMAIL_ALERTS = false
- Website content is cached for speed; any edit in the sheet clears it.
  If a change doesn't show, use menu -> "Refresh website now".
- If the sheet can't be reached, the website keeps showing its built-in
  gallery/ticker/holidays — nothing breaks.
- Uploads: photos are shrunk in the parent's phone before sending (fast on
  mobile data). PDFs up to 5 MB.
- Privacy: don't share the sheet or the Uploads folder publicly. Share the
  sheet only with staff who need it.
- Free Gmail sends ~100 alert emails per day — plenty for a school.
