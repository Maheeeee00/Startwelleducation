1. Learning objectives

By the end of this lecture you should be able to:

  1. Identify cells, ranges, rows, columns, worksheets and workbooks.
  2. Write formulas with arithmetic operators and the order of operations.
  3. Use SUM, AVERAGE, MIN, MAX, COUNT, COUNTIF and IF functions.
  4. Explain relative and absolute references and use the fill handle.
  5. Sort, filter, apply conditional formatting and create suitable charts.

Relevant CLOs: CLO 3 – Apply ICT tools in everyday, academic and professional activities.

2. Introduction

A spreadsheet is a grid that calculates. Shopkeepers use it to track stock, teachers to compile results, accountants to prepare budgets and researchers to analyse survey data. The power of a spreadsheet is that formulas recalculate instantly when any number changes, so you can ask ‘what if?’ questions. In this lecture we build a sales sheet for Bhimber Mart, a fictional store in the main bazaar, and use it to learn the formulas and tools that cover most everyday spreadsheet work.

Roman Urdu: Spreadsheet hisaab kitaab ka digital register hai. Har formula = se shuru hota hai. SUM, AVERAGE, IF jaise functions se total, average aur ‘Low stock’ jaise faisle khud ho jate hain. Sorting, filtering aur charts se data samajhna aasan hota hai. Hum Bhimber Mart ki sales sheet par practice karenge.

3. Detailed explanation

3.1 Spreadsheet basics

A workbook is the whole file; it contains one or more worksheets (tabs). Each sheet is a grid of columns labelled with letters (A, B, C …) and rows labelled with numbers (1, 2, 3 …). Their intersection is a cell, identified by its address, such as B4. A group of cells is a range, written with a colon, such as B2:B21. Cells hold text (labels), numbers, dates or formulas. The Name Box shows the selected cell’s address and the Formula Bar shows what the cell really contains. Excel is part of Microsoft Office; Google Sheets is free in a browser and saves to Drive automatically.

Key points
  • Workbook → Worksheets → Cells
  • Cell address: column letter + row number (C5)
  • Range: A1:D10
  • Formula Bar shows the real content

3.2 Formulas and operators

Every formula begins with an equals sign. It can use numbers, cell addresses and operators: + (add), - (subtract), * (multiply), / (divide) and ^ (power). Spreadsheets follow the mathematical order of operations, BODMAS/PEMDAS: brackets first, then powers, then multiplication and division, then addition and subtraction. So =2+3*4 gives 14 while =(2+3)*4 gives 20. Using cell addresses instead of typed numbers is what makes a spreadsheet useful: =C2*D2 calculates a line total and updates automatically when the price in C2 changes.

Key points
  • Always start with =
  • Operators: + - * / ^
  • Brackets control order: =(B2+C2)/2
  • Use addresses, not typed numbers

3.3 Essential functions

A function is a built-in formula with a name and arguments in brackets. SUM adds a range: =SUM(E2:E21). AVERAGE finds the mean, MIN and MAX the smallest and largest values, COUNT counts cells with numbers and COUNTA counts non-empty cells. COUNTIF counts cells meeting a condition, such as =COUNTIF(F2:F21,"Low stock"). IF makes a decision: =IF(D2<10,"Low stock","OK") shows ‘Low stock’ when the quantity is below 10. Text in formulas must be in straight double quotes. Functions can be combined, for example =IF(E2>AVERAGE(E$2:E$21),"Above average","Below").

Key points
  • =SUM(range) =AVERAGE(range)
  • =MIN(range) =MAX(range)
  • =COUNT(range) =COUNTA(range)
  • =COUNTIF(range,condition)
  • =IF(test, value_if_true, value_if_false)

3.4 Relative and absolute references

When you copy a formula down a column with the fill handle (the small square at the bottom-right of a selected cell), the cell addresses change relative to the new position: =C2*D2 in row 2 becomes =C3*D3 in row 3. This is a relative reference and is usually what you want. Sometimes a formula must always point to one fixed cell, such as a tax rate or discount stored in H1. Add dollar signs to make it absolute: =E2*$H$1. Press F4 in Excel to toggle dollar signs. Mixed references ($H1 or H$1) fix only the column or only the row.

Key points
  • Relative: C2 (changes when copied)
  • Absolute: $H$1 (always the same cell)
  • Mixed: $H1 or H$1
  • F4 toggles reference types

3.5 Sorting, filtering, formatting and charts

Sorting rearranges rows by a column, for example highest sales first; always select the whole table so rows stay together. Filtering (Data → Filter) shows only rows that meet a condition, such as category ‘Grocery’, without deleting anything. Conditional formatting colours cells automatically, for example red for quantity below 10. Number formats display values as currency (Rs), percentages or dates. Charts turn numbers into pictures: a column or bar chart compares items, a line chart shows change over time and a pie chart shows parts of a whole (use it only for a few categories that add to 100%). Every chart needs a title and labelled axes.

Key points
  • Sort A→Z / largest→smallest
  • Filter to show matching rows
  • Conditional formatting rules
  • Column/bar = compare · Line = trend · Pie = parts of whole

4. Technical terminology

Cell
The intersection of a row and a column, such as B3.
Range
A rectangular group of cells, such as A1:C10.
Formula
An expression beginning with = that calculates a value.
Function
A built-in formula such as SUM or IF.
Argument
A value or range supplied inside a function’s brackets.
Fill handle
Small square used to copy formulas to adjacent cells.
Absolute reference
A cell reference fixed with $ signs, such as $H$1.
Conditional formatting
Formatting that changes automatically based on cell values.

Important definitions

Spreadsheet: Application software that organises data in rows and columns and performs calculations using formulas.
Workbook: A spreadsheet file containing one or more worksheets.
Chart: A graphical representation of spreadsheet data.

5. Step-by-step example

Worked example: Bhimber Mart sales sheet

  1. Headings in row 1: Item (A), Category (B), Price Rs (C), Quantity Sold (D), Total Rs (E), Stock Left (F), Status (G).
  2. Enter 20 items, for example Rice 5kg, Grocery, 1450, 32, …, 8.
  3. In E2 type =C2*D2 and drag the fill handle down to E21.
  4. In E22 type =SUM(E2:E21) for total sales and in E23 =AVERAGE(E2:E21).
  5. In G2 type =IF(F2<10,"Low stock","OK") and fill down.
  6. In H1 type a discount of 5% and in I2 =E2*(1-$H$1); fill down to see discounted totals.
  7. Select A1:G21 and sort by Total Rs, largest to smallest.
  8. Apply conditional formatting: Status equals ‘Low stock’ → red fill.
  9. Select Item and Total columns and insert a column chart titled ‘Bhimber Mart – Sales by Item’.

6. Pakistan-based examples

School result sheets

Many schools in Azad Kashmir compile marks in Excel: SUM for totals, percentage with =total/max*100, and IF for pass or fail, before printing result cards.

Household budgets

Families track electricity bills (with slab rates), school fees and groceries in a simple sheet to plan monthly spending.

7. Bhimber case study

Case study: monthly review at Bhimber Mart

At the end of the month the owner of Bhimber Mart wants to know which items earned the most, which are about to run out and whether a 5% Eid discount on all items is affordable. Using the sales sheet, the student sorts by Total Rs to find the top five items, filters Status to ‘Low stock’ to prepare a reorder list, changes the discount cell from 5% to 10% to see the effect on revenue instantly, and prints a column chart for the owner.

Questions for analysis
  1. Which features answered each of the owner’s three questions?
  2. Why must the discount cell be an absolute reference?
  3. Which chart type best shows sales by item, and why?

8. Real-life applications

  • Shop sales, stock and accounts
  • Student result sheets and attendance
  • Household and event budgets
  • Survey data analysis
  • Salary sheets and fee records

9. Advantages and disadvantages

Advantages

  • Automatic recalculation when data changes
  • Fast analysis with functions, sorting and filtering
  • Charts make patterns easy to see
  • Sheets allows real-time sharing

Disadvantages

  • A single wrong formula can spread errors
  • Large datasets can become slow
  • Advanced functions take time to learn
  • Data can be accidentally overwritten without protection

12. Important points for examination

  • Every formula starts with =; examiners deduct marks if it is missing.
  • Know the syntax of IF exactly, with three arguments.
  • Explain relative vs absolute references with an example using $.
  • Match chart types to purposes.

13. Lecture summary

  • A workbook holds worksheets made of cells with addresses.
  • Formulas start with = and follow the order of operations.
  • SUM, AVERAGE, MIN, MAX, COUNT, COUNTIF and IF cover most daily tasks.
  • Relative references change when copied; absolute ($) references do not.
  • Sort, filter, conditional formatting and charts turn data into decisions.

16. Assignment

Using the provided Bhimber Mart dataset (20 items), compute totals, overall SUM and AVERAGE, a Status column with IF, a discounted total using an absolute reference, COUNTIF of low-stock items, conditional formatting, a sorted top-five list and one correctly titled chart.
