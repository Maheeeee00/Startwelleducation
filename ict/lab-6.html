6. Required hardware

  • Computer

7. Required software

  • Microsoft Excel or Google Sheets
  • Bhimber Mart sample dataset (CSV) from the Resources page

8. Learning objectives

  1. Import a dataset and write formulas.
  2. Use functions and absolute references.
  3. Sort, filter, format and chart data.

9. Background theory

Formulas calculate from cell references; functions summarise ranges; absolute references fix constants; charts visualise patterns.

Revise the detailed explanation in Lecture 6 before starting.

10. Step-by-step procedure

  1. Download bhimber-mart-sales.csv from the Resources page and open it in Excel (or File → Import in Sheets).
  2. Save as Lab06_YourName.xlsx (or rename the Sheet).
  3. Add a column Total Rs with =C2*D2 (adjust to your columns) and fill down.
  4. Below the table, calculate Total sales (SUM), Average sale (AVERAGE), Highest (MAX), Lowest (MIN) and Number of items (COUNTA).
  5. Add a Status column: =IF(StockLeft<10,"Low stock","OK") using the correct cell.
  6. Use COUNTIF to count Low stock items.
  7. Type 5% in a cell labelled Discount. Add Discounted Total = Total*(1-$Discount cell$) and fill down. Change the discount to 10% and observe.
  8. Format price and total columns as currency (Rs) with no decimals.
  9. Apply conditional formatting to Status: ‘Low stock’ in red.
  10. Turn on Filter and show only the Grocery category; copy the result to a new sheet named Grocery.
  11. Sort the main table by Total, largest to smallest.
  12. Insert a column chart of the top 10 items by Total with a title and axis labels; insert a pie chart of sales by category using a small summary table (SUMIF).
  13. Freeze the header row (View → Freeze Panes).

11. Practical task

Complete the Bhimber Mart analysis workbook with formulas, status flags, discount scenario, filtered Grocery sheet, sorted table and two charts.

12. Expected output

Lab06_YourName.xlsx with sheets Sales and Grocery, summary statistics, two titled charts and a short findings note.

14. Troubleshooting guide

ProblemSolution
Formula shows as textThe cell is formatted as Text or the = is missing; change format to General and retype.
#VALUE! errorA number column contains text such as ‘Rs’; remove it and use number formatting instead.
Discount gives wrong values after copyingThe discount cell is not absolute; add $ signs.
Sorting mixed up items and pricesOnly one column was selected; undo and select the whole table.

15. Lab questions

  1. What was the total sales figure?
  2. How many items were Low stock?
  3. What changed when the discount moved to 10%?
  4. Which category earned the most?

16. Viva questions

  1. Write the syntax of IF.
  2. What does $ do in a reference?
  3. Difference between COUNT and COUNTA?
  4. Why use a column chart here?
