1. Learning objectives

By the end of this lecture you should be able to:

  1. Compare Google Drive, OneDrive and Dropbox by storage, integration and sharing.
  2. Set sharing permissions (Viewer, Commenter, Editor) and link access correctly.
  3. Design a logical folder structure and apply a file naming convention.
  4. Use OneNote or Evernote to organise course notes.
  5. Apply the 3-2-1 backup rule and explain sync and version history.

Relevant CLOs: CLO 2 – Identify different ICT platforms and tools.; CLO 3 – Apply ICT tools in everyday, academic and professional activities.

2. Introduction

Students lose work every semester: a USB drive is left in a computer lab, a phone is stolen, a laptop hard disk fails the night before a deadline. Cloud storage and good file habits prevent almost all of these disasters. In Lecture 1 we met cloud storage as an idea; now we use it properly. We compare the main services, learn to share files safely, design folders that make sense a year later, take organised digital notes and build a backup routine that would survive losing any single device.

Roman Urdu: Cloud storage se aap ki files har device par mil jati hain aur share karna aasan hota hai. Sahi folder structure aur file ke naam rakhne ke usool waqt bachate hain. Sharing mein ‘View only’ sab se mehfooz hai. Backup ka usool: 3 copies, 2 alag jagah, 1 ghar se bahar (cloud).

3. Detailed explanation

3.1 Cloud storage services

Google Drive gives 15 GB free shared across Gmail, Drive and Google Photos, and integrates with Docs, Sheets, Slides and Classroom. Microsoft OneDrive gives 5 GB free (more with a Microsoft 365 or university account) and integrates with Word, Excel, PowerPoint and Windows File Explorer. Dropbox gives 2 GB free on its basic plan and is known for simple, reliable sync across devices. All three offer desktop and mobile apps that sync a local folder with the cloud, so a file edited on the lab computer appears on your phone. Free storage limits change over time, so check the provider’s current plan.

Key points
  • Google Drive: 15 GB free, Google Workspace integration
  • OneDrive: 5 GB free, Microsoft Office and Windows integration
  • Dropbox: 2 GB free, simple sync
  • All: web, desktop and mobile apps

3.2 Sync, version history and offline access

Sync means keeping the same files identical on several devices and the cloud. When you change a file on one device, the sync client uploads the change and other devices download it. Version history keeps earlier versions so you can restore yesterday’s copy if you overwrite something by mistake: in Google Docs use File → Version history, and in Drive or OneDrive right-click a file → Version history. Files can be made available offline so you can work during internet outages; changes upload when the connection returns. Deleted files go to the Bin/Recycle bin and can usually be restored for about 30 days.

Key points
  • Sync keeps devices identical
  • Version history restores older copies
  • Offline mode for outages
  • Bin keeps deleted files for a limited time

3.3 Sharing and permissions

Cloud sharing sends a link instead of a file copy, so everyone sees the latest version. Each person can be given a role: Viewer (can only see), Commenter (can see and comment) or Editor (can change, and by default share). Link sharing can be Restricted (only people added by name), limited to your organisation (for example everyone with a university account) or ‘Anyone with the link’. The safest default is Restricted or ‘Anyone with the link – Viewer’. Never give Editor access to people who do not need it, and remove access when a project ends. Owners can also prevent editors from re-sharing and disable downloading for viewers.

Key points
  • Viewer · Commenter · Editor · Owner
  • Restricted vs organisation vs anyone with link
  • Least privilege: give minimum access needed
  • Review and remove access regularly

3.4 Folder structure and file naming

A folder structure is a hierarchy that matches how you think about your work, for example University → Semester 1 → ICT → Lectures / Labs / Assignments / Exams. Keep it shallow (three or four levels) and consistent across subjects. A file naming convention makes files easy to sort and find: include what, who and when, avoid spaces and special characters, and use dates in YYYY-MM-DD format so files sort in order. Examples: ICT_Lab03_AliKhan_2026-03-14.docx, ICT_Assignment2_v2_AliKhan.pdf. Avoid names like ‘final final new.docx’.

Key points
  • Hierarchy: Year → Semester → Course → Type
  • 3–4 levels deep
  • Course_Type_Number_Name_Date
  • YYYY-MM-DD dates; no spaces; version numbers v1, v2

3.5 Digital note-taking and backup

Microsoft OneNote organises notes into notebooks, sections and pages, like a ring binder; it accepts typed text, handwriting, images, audio and web clippings, and syncs through OneDrive. Evernote organises notes into notebooks and tags and offers powerful search, including text inside images on some plans. Google Keep offers quick notes and checklists. Digital notes are searchable and backed up, but only if you organise them. The 3-2-1 backup rule says: keep 3 copies of important data, on 2 different types of storage (for example laptop and USB drive), with 1 copy off-site (the cloud).

Key points
  • OneNote: notebooks → sections → pages
  • Evernote: notebooks + tags + search
  • Google Keep: quick notes, checklists
  • 3-2-1 rule: 3 copies, 2 media, 1 off-site

4. Technical terminology

Sync
Automatically keeping files identical across devices and the cloud.
Version history
Saved earlier versions of a file that can be restored.
Permission
The level of access given to a shared file: view, comment or edit.
Link sharing
Sharing a file by sending a URL rather than a copy.
Naming convention
A consistent rule for naming files.
Backup
An extra copy of data kept to recover from loss.
Off-site
Stored in a different physical location, such as the cloud.
Notebook
In OneNote/Evernote, a top-level container of notes.

Important definitions

Cloud storage: A service that stores files on remote servers accessible over the internet.
File management: Organising, naming, storing and backing up files so they can be found and protected.
3-2-1 backup rule: Keep three copies of data on two types of media with one copy off-site.

5. Step-by-step example

Worked example: sharing a group folder safely

  1. In Google Drive click New → Folder and name it ICT_GroupProject_SectionA.
  2. Create subfolders: 01_Research, 02_Drafts, 03_Final, 04_Presentation.
  3. Right-click the main folder → Share.
  4. Add three group members by email as Editor.
  5. Add the instructor as Commenter.
  6. Keep General access as Restricted.
  7. Click the settings gear and untick ‘Editors can change permissions and share’.
  8. Click Send; members receive an email with the link.

6. Pakistan-based examples

University accounts

Many Pakistani universities provide Google Workspace for Education or Microsoft 365 accounts with larger cloud storage for students, accessed with the university email.

Load-shedding and backups

In areas with power cuts, enabling auto-save and cloud sync means work typed before a cut is already saved when power returns.

7. Bhimber case study

Case study: a lost USB drive in Bhimber

A student at a college in Bhimber keeps all semester work on one USB drive. Two days before submission, the drive stops working. Her classmate, who uses Google Drive sync with a folder structure ICT → Labs → Lab01–Lab08 and file names like ICT_Lab05_Sana_2026-03-02.docx, simply opens the files on a lab computer. After this, the first student adopts the 3-2-1 rule: laptop copy, USB copy and a Google Drive copy, with weekly checks.

Questions for analysis
  1. Explain how the 3-2-1 rule protects her now.
  2. Why does a date in YYYY-MM-DD format help?
  3. What permission should she use when sharing her lab files with the instructor?

8. Real-life applications

  • Business document storage for small shops

9. Advantages and disadvantages

Advantages

  • Access from any device
  • Easy, controlled sharing
  • Automatic backup and version history
  • Saves money on physical storage

Disadvantages

  • Requires internet for sync and access
  • Free storage is limited
  • Privacy depends on account security
  • Wrong sharing settings can expose data

13. Lecture summary

  • Drive, OneDrive and Dropbox store and sync files in the cloud.
  • Version history and the Bin recover mistakes.
  • Share with the least privilege needed; prefer Restricted links.
  • Use shallow folder structures and consistent naming with dates.
  • Use OneNote/Evernote for notes and follow the 3-2-1 backup rule.
