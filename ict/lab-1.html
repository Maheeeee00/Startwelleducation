Requirements

6. Required hardware

  • Desktop or laptop computer
  • Smartphone
  • USB flash drive
  • Lab network (switch and router)

7. Required software

  • Windows 10/11 or any operating system
  • File Explorer or file manager
  • Web browser
  • Google Drive or OneDrive account

8. Learning objectives

  1. Identify the hardware components of a lab computer and a phone.
  2. Find the operating system and installed applications.
  3. Observe how the lab computers connect to the network.
  4. Save the same file locally and in the cloud and compare.

9. Background theory

Every ICT system is made of hardware, software, networks and storage. Operating systems show hardware details in their settings. Local storage is attached to the device; cloud storage is reached through the internet after logging in.

Revise the detailed explanation in Lecture 1 before starting.

10. Step-by-step procedure

  1. Switch on the computer and log in with the lab account.
  2. Press Windows + Pause (or open Settings → System → About) and note the processor, installed RAM and Windows edition.
  3. Open File Explorer → This PC. Note each drive letter, its total size and its free space.
  4. Open Device Manager (right-click Start → Device Manager) and list one item under Keyboards, Display adapters, Network adapters and Disk drives.
  5. Open Settings → Apps and list five installed applications. Mark each as system or application software.
  6. Open Command Prompt and type ipconfig. Note the IPv4 address and Default Gateway. Explain in one line what the gateway is.
  7. Follow the network cable from your computer to the switch and note how the switch connects to the router.
  8. On your phone, open Settings → About phone and note model, Android/iOS version, RAM and storage.
  9. Create a text file named Lab01_YourName.txt with your findings so far. Save it in Documents (local).
  10. Open drive.google.com, create a folder ICT-Labs and upload the same file (cloud).
  11. Turn off Wi-Fi on the phone and try to open the file from Drive. Record what happens.
  12. Complete the comparison table and submit.

11. Practical task

Complete a ‘System inventory sheet’ with three tables: (1) lab computer hardware by category, (2) software list classified as system or application, (3) network and storage details including IP address, gateway, local drive free space and cloud storage free space.

12. Expected output

A completed inventory sheet saved as Lab01_YourName in both Documents and your ICT-Labs cloud folder, plus a short paragraph comparing the two storage locations.

14. Troubleshooting guide

ProblemSolution
Settings → About does not openSearch ‘System Information’ in the Start menu and use msinfo32 instead.
ipconfig shows 169.254.x.xThe computer did not get an address from the router; check the cable or ask the lab attendant to restart the switch.
Drive upload stuck at 0%The internet is slow or blocked; try again later or upload from your phone.
Device Manager shows a yellow warning iconA driver is missing; note the device name for the lab report.

15. Lab questions

  1. How much RAM does the lab computer have, and why does RAM matter?
  2. Which software did you classify as system software, and why?
  3. What is the purpose of the default gateway?
  4. Which copy of your file could you open without internet?

16. Viva questions

  1. What is the difference between RAM and storage?
  2. Name the network type used in the lab.
  3. What happens to cloud files if you forget your password?
  4. Is a driver system software or application software?
