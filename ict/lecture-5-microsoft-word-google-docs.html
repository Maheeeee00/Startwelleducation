1. Learning objectives

By the end of this lecture you should be able to:

  1. Apply character and paragraph formatting consistently.
  2. Use built-in heading styles and generate an automatic table of contents.
  3. Insert page numbers, headers, footers, section breaks and a title page.
  4. Insert and format tables, images and captions.
  5. Add citations, use comments and track changes, share and export to PDF.

Relevant CLOs: CLO 3 – Apply ICT tools in everyday, academic and professional activities.

2. Introduction

A word processor is the tool you will use most often at university: for assignments, lab reports, project documentation, applications and your CV. Most students use Word like a typewriter, pressing Enter repeatedly to move to a new page and making headings bold by hand. That makes documents hard to edit and impossible to navigate. This lecture shows how professionals work: they let styles control the appearance, let the software number pages and build the contents table, and use collaboration features so a group can work on one file without emailing versions back and forth.

Roman Urdu: Word aur Google Docs se assignment, report aur CV banaye jaate hain. Asal taqat styles mein hai: Heading 1, Heading 2 lagayein to table of contents khud ban jata hai. Page numbers, header/footer, tables aur references ek document ko professional banate hain. Docs mein comments aur sharing se group work aasan hota hai.

3. Detailed explanation

3.1 Word processors and formatting

Microsoft Word is a desktop application, part of Microsoft Office or Microsoft 365, and also runs in a browser as Word for the web. Google Docs runs in a browser, saves automatically to Google Drive and is free with a Google account. Both handle the same core tasks. Character formatting changes text: font, size, bold, italic, underline, colour. Paragraph formatting changes whole paragraphs: alignment (left, centre, right, justify), line spacing, spacing before and after, indentation, bullets and numbering. For academic work, a clean font such as Calibri, Times New Roman or Arial at 11–12 point with 1.15–1.5 line spacing is standard.

Key points
  • Character: font, size, bold, italic, colour
  • Paragraph: alignment, spacing, indentation, lists
  • Page: margins, orientation, size (A4 in Pakistan)
  • Format Painter copies formatting quickly

3.2 Styles and headings

A style is a saved set of formatting with a name, such as Normal, Title, Heading 1 and Heading 2. When you apply Heading 1 to every chapter title, three things happen: all chapters look identical, changing the style once updates every heading, and the software understands the document’s structure. That structure powers the Navigation Pane in Word and the document outline in Docs, which let you jump to any section, and it is required for an automatic table of contents. Use Heading 1 for main sections, Heading 2 for subsections and Heading 3 for smaller parts; never skip levels.

Key points
  • Apply styles from Home → Styles (Word) or the ‘Normal text’ menu (Docs)
  • Modify a style once to update all headings
  • Navigation Pane / Document outline
  • Heading 1 → Heading 2 → Heading 3

3.3 Page layout: numbers, headers, footers and breaks

Page numbers are inserted from Insert → Page Number (Word) or Insert → Page numbers (Docs) and update automatically. Headers and footers repeat on every page and usually hold the document title, course code or student name. A page break (Ctrl + Enter) starts a new page cleanly instead of pressing Enter many times. A section break in Word lets different parts of a document have different layouts, for example no page number on the title page, Roman numerals for the contents pages and Arabic numerals from the introduction onward. ‘Different first page’ hides the header on the title page.

Key points
  • Ctrl + Enter = page break
  • Insert → Page Number
  • Different first page for title pages
  • Section breaks for different numbering

3.4 Table of contents, tables and images

Once headings use styles, insert a table of contents from References → Table of Contents (Word) or Insert → Table of contents (Docs). When headings or page numbers change, click Update Table. Tables organise data in rows and columns: insert them from Insert → Table, add a header row, use table styles and keep tables simple. Images are inserted from Insert → Pictures; set text wrapping (In line with text is safest), resize from the corner to keep proportions and add a caption (References → Insert Caption) such as ‘Figure 1: Bhimber Mart sales chart’. Only use images you have the right to use.

Key points
  • References → Table of Contents → Update Table
  • Tables: header row, table styles, alignment
  • Images: wrap text, keep aspect ratio, captions
  • Insert → Symbol and Equation for special characters

3.5 References, comments and collaboration

Academic writing must credit sources. Word’s References → Insert Citation stores sources and creates a bibliography automatically in styles such as APA or IEEE; Docs offers Tools → Citations. Footnotes add notes at the bottom of a page. For group work, comments let reviewers suggest changes without editing the text, and Track Changes (Word) or Suggesting mode (Docs) records every edit so the author can accept or reject it. Sharing in Docs or OneDrive uses links with Viewer, Commenter or Editor permission. Finally, export to PDF (File → Save As → PDF, or File → Download → PDF) before submitting, so formatting cannot change on another computer.

Key points
  • Insert Citation and Bibliography (APA, IEEE)
  • Footnotes
  • Comments, Track Changes / Suggesting
  • Share: Viewer, Commenter, Editor
  • Export to PDF before submitting

4. Technical terminology

Style
A named set of formatting applied to text, such as Heading 1.
Template
A pre-designed document used as a starting point.
Section break
A divider that allows different page layouts in one document.
Header/Footer
Area at the top or bottom of every page.
Track Changes
A feature that records edits for review.
Caption
A numbered label for a table or figure.
Bibliography
A list of sources cited in a document.
Format Painter
Tool that copies formatting from one place to another.

Important definitions

Word processor: Application software used to create, edit, format and print text documents.
Table of contents: An automatically generated list of headings with page numbers.
Citation: A reference within the text to the source of information.

5. Step-by-step example

Worked example: building an automatic table of contents

  1. Type your headings: Introduction, Literature Review, Method, Results, Conclusion.
  2. Click on ‘Introduction’ and choose Heading 1; repeat for the other main headings.
  3. Apply Heading 2 to subheadings such as ‘2.1 ICT in Pakistan’.
  4. Place the cursor on page 2 (after the title page).
  5. Word: References → Table of Contents → Automatic Table 1. Docs: Insert → Table of contents.
  6. Add new text so headings move; then click Update Table and choose ‘Update entire table’.
  7. Check that page numbers in the table match the document.

6. Pakistan-based examples

Thesis formatting

Pakistani universities publish thesis and project report formats that specify margins, fonts, heading numbering and citation style. Using styles and automatic contents makes these rules easy to follow.

Government forms

Many official forms are distributed as Word or PDF documents; knowing tables and form fields helps fill and print them correctly.

7. Bhimber case study

Case study: a group report on Bhimber’s water supply

Four BS students must submit a 15-page report on the water supply of Bhimber city. In the past they emailed Word files back and forth and lost changes. This time the group leader creates a Google Doc, shares it as Editor with members and as Commenter with the instructor. Each member writes one chapter under Heading 1. They insert a table of survey results, two photos with captions and five citations. Suggesting mode is used for editing. On the final day they insert the contents table, add page numbers, and download a PDF for submission.

Questions for analysis
  1. Which features prevented lost changes?
  2. Why should the instructor have Commenter rather than Editor access?
  3. What must the group do to the contents table after final edits?

8. Real-life applications

  • Assignments, lab reports and theses
  • CVs and cover letters
  • Office letters, notices and memos
  • School question papers and result sheets
  • Group reports and proposals

9. Advantages and disadvantages

Advantages

  • Styles make long documents consistent and easy to update
  • Automatic contents, numbering and citations save time
  • Real-time collaboration in Docs and Word online
  • Export to PDF preserves formatting

Disadvantages

  • Advanced features have a learning curve
  • Formatting may shift between Word and Docs
  • Desktop Word needs a licence
  • Online editing needs internet

12. Important points for examination

  • Explain why styles are needed for an automatic table of contents.
  • Know keyboard shortcuts: Ctrl+B, Ctrl+I, Ctrl+U, Ctrl+Enter, Ctrl+S, Ctrl+Z.
  • Compare Word and Docs in at least four points.
  • Describe steps to insert page numbers and a contents table.

13. Lecture summary

  • Use styles, not manual bold, for headings.
  • Heading styles enable navigation and automatic contents.
  • Page numbers, headers, footers and breaks control layout.
  • Tables, images and captions present information clearly.
  • Use citations, comments, sharing and PDF export for academic work.

16. Assignment

Create a 3–4 page assignment on ‘Uses of ICT in my district’ with: title page without page number, automatic table of contents, at least three Heading 1 and two Heading 2 sections, one table, one image with caption, page numbers in the footer, header with course code, three citations with a bibliography, exported as PDF.

Homework

Open any old document you wrote and apply Heading styles to its titles. Open the Navigation Pane and take a screenshot of the structure.
