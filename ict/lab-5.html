8. Learning objectives

  1. Prepare a multi-page document with styles and automatic contents.
  2. Insert page numbers, header, table, image and caption.
  3. Add citations and export as PDF.

9. Background theory

Styles define structure. The TOC, navigation and captions are generated from structure. PDF preserves the final layout.

Revise the detailed explanation in Lecture 5 before starting.

10. Step-by-step procedure

  1. Open the practice text file provided (or type five short sections about ICT uses).
  2. Page 1: create a title page with university name, course title, assignment title, your name and roll number. Insert a page break (Ctrl+Enter).
  3. Apply Heading 1 to five section titles and Heading 2 to at least two subsections.
  4. Modify Heading 1 to a different colour and size; confirm all headings change.
  5. On page 2, insert an automatic table of contents.
  6. Insert a page number in the footer. Enable ‘Different first page’ so the title page has no number.
  7. Add a header with ‘ICT – Applications of ICT’ and your roll number.
  8. Insert a 4×5 table of Bhimber Mart items with Item, Price, Quantity, Total; apply a table style.
  9. Insert an image related to ICT, set wrapping to ‘In line with text’ and add the caption ‘Figure 1: …’.
  10. Insert three citations (References → Insert Citation or Tools → Citations) and a bibliography at the end.
  11. Turn on Track Changes/Suggesting, make one edit, add one comment, then accept the change.
  12. Update the table of contents, then export as Lab05_YourName.pdf.

11. Practical task

Produce a formatted 4–5 page document with title page, TOC, styled headings, header/footer with page numbers, table, captioned image, citations and bibliography, exported to PDF.

12. Expected output

Lab05_YourName.docx (or Doc) and Lab05_YourName.pdf in the ICT-Labs folder.

14. Troubleshooting guide

ProblemSolution
TOC says ‘No table of contents entries found’Headings are not using Heading styles; apply Heading 1/2 and update.
Page number appears on title pageDouble-click the footer and tick ‘Different First Page’.
Image jumps aroundSet Wrap Text to ‘In Line with Text’.
TOC page numbers wrongRight-click the TOC → Update Field → Update entire table.

15. Lab questions

  1. How did modifying Heading 1 affect the document?
  2. Why did you use ‘Different first page’?
  3. Where is the caption numbering stored?
  4. What style did you choose for citations?

16. Viva questions

  1. What is a style?
  2. How do you update a TOC?
  3. What is the shortcut for a page break?
  4. Why export to PDF?
