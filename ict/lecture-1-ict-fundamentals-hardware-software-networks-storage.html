1. Learning objectives

By the end of this lecture you should be able to:

  1. Define ICT and explain each of its three parts: information, communication and technology.
  2. Classify hardware into input, processing, output, storage and communication devices.
  3. Distinguish system software from application software with examples.
  4. Compare LAN, MAN, WAN and the internet by size, ownership and speed.
  5. Compare local storage with cloud storage and choose the right one for a given task.

Relevant CLOs: CLO 1 – Understand basic ICT concepts, components and scope.

2. Introduction

Every time a student in Bhimber sends a WhatsApp voice note, checks a result on a board website or prints an assignment at a photocopy shop, an ICT system is at work. Information and Communication Technology (ICT) is the combination of devices, programs and networks that let people create, store, process, share and receive information. Computer science studies how these systems are built; ICT as a General Education subject focuses on using them well. This first lecture gives you the vocabulary that the rest of the course depends on: once you can name the parts of an ICT system, you can reason about why a file will not open, why the internet is slow in the lab, or where your photos are actually kept.

Roman Urdu: ICT ka matlab hai Information and Communication Technology: woh tamam devices, programs aur networks jin se hum information banate, save karte, process karte aur doosron tak bhejte hain. Har ICT system chaar cheezon se banta hai: hardware (jo cheez chhoo sakte hain), software (instructions), network (rabta) aur storage (yaadasht).

3. Detailed explanation

3.1 What is ICT?

ICT joins three ideas. Information is processed, meaningful data: a list of marks is data, but ‘Ali got the highest marks in Class 9’ is information. Communication is the transfer of that information between people or machines, by text, voice, image or video. Technology is the set of tools that makes the first two fast and cheap. ICT is wider than IT (Information Technology) because it also includes telecommunication: mobile networks, radio, television and the internet. An ICT system always follows the same cycle: input, processing, output, storage, and often communication to another system.

Key points
  • Data: raw facts (numbers, words, readings) without context.
  • Information: data that has been organised and given meaning.
  • IT focuses on computing; ICT adds telecommunication and broadcasting.
  • The information processing cycle: Input → Process → Output → Store → Communicate.

3.2 Hardware: the physical parts

Hardware is any part of an ICT system you can touch. It is easiest to understand by the job each device does in the processing cycle. Input devices bring data in, the processor (CPU) works on it using fast temporary memory (RAM), output devices show or print results, storage devices keep data when the power is off, and communication devices connect the system to others. A smartphone contains all five groups in one body: touch screen and camera (input), processor and RAM (processing), screen and speaker (output), internal flash storage (storage) and Wi-Fi, 4G and Bluetooth radios (communication).

Key points
  • Input: keyboard, mouse, touch screen, scanner, microphone, webcam, barcode reader.
  • Processing: CPU (the ‘brain’), GPU for graphics, RAM as short-term working memory.
  • Output: monitor, printer, speakers, projector.
  • Storage: hard disk (HDD), solid-state drive (SSD), USB flash drive, memory card.
  • Communication: network card, Wi-Fi router, modem, mobile radio.

3.3 Software: the instructions

Software is the set of instructions that tells hardware what to do. System software manages the machine itself: the operating system (Windows, Android, macOS, Linux, iOS) controls files, memory, devices and users, while utility programs such as antivirus, backup and disk cleanup keep it healthy. Application software helps the user complete a task: Word for documents, Excel for calculations, Chrome for browsing, JazzCash for payments. Device drivers are small pieces of system software that let the operating system talk to a specific printer, scanner or graphics card. Software can be proprietary (Microsoft Office, paid licence), free (Google Docs, free to use but owned by a company) or open source (LibreOffice, source code anyone can study).

Key points
  • System software: operating systems, drivers, utilities.
  • Application software: word processors, spreadsheets, browsers, apps.
  • Licensing types: proprietary, freeware, open source, subscription (Microsoft 365).
  • Without an operating system, application software cannot run.

3.4 Networks: connecting systems

A network is two or more devices connected so they can share data and resources such as a printer or an internet connection. Networks are grouped mainly by the area they cover. A Personal Area Network (PAN) links devices around one person, such as earbuds connected by Bluetooth. A Local Area Network (LAN) covers one building or campus, like the computer lab of a school, and is usually owned by that organisation. A Metropolitan Area Network (MAN) covers a city. A Wide Area Network (WAN) connects sites across cities or countries, such as a bank linking all its branches. The internet is the largest WAN: a global network of networks that uses common rules called protocols (TCP/IP). Devices connect by cable (Ethernet, fibre) or wirelessly (Wi-Fi, 4G/5G).

Key points
  • PAN: around one person (Bluetooth).
  • LAN: one building or campus, high speed, privately owned.
  • MAN: one city, for example a cable operator’s network.
  • WAN: many cities or countries, often leased lines.
  • Internet: the global network of networks using TCP/IP.

3.5 Storage: local and cloud

Storage keeps data when the power is switched off. Local storage is inside or attached to your own device: the hard disk of a laptop, the phone’s internal memory or a USB drive. It works without internet and you control it physically, but it can be lost, stolen or damaged. Cloud storage keeps your files on servers owned by a provider such as Google Drive, Microsoft OneDrive or Dropbox, and you reach them through the internet. It can be opened from any device and makes sharing easy, but it needs an internet connection and depends on a strong account password. RAM is not storage in this sense: it is volatile and loses its content when power is lost. Storage is measured in bytes: 1 KB = 1,024 bytes, 1 MB = 1,024 KB, 1 GB = 1,024 MB, 1 TB = 1,024 GB.

Key points
  • Primary memory: RAM (volatile, fast) and ROM (non-volatile, holds start-up instructions).
  • Secondary storage: HDD, SSD, USB, memory card (non-volatile).
  • Cloud storage: provider servers reached over the internet.
  • Typical sizes: a photo about 3 MB, a song about 5 MB, an HD film about 2 GB.

4. Technical terminology

CPU
Central Processing Unit; carries out instructions and calculations.
RAM
Random Access Memory; fast temporary memory that is cleared when power is off.
Operating system
System software that manages hardware, files and applications.
Device driver
Software that lets the operating system control a specific device.
Protocol
An agreed set of rules for communication, such as TCP/IP or HTTP.
Bandwidth
The amount of data a connection can carry per second, measured in Mbps.
Cloud storage
Saving files on a provider’s internet servers instead of your own device.
Peripheral
An external device connected to a computer, such as a printer.

Important definitions

ICT: The set of technologies used to create, store, process, transmit and receive information, including computers, software, networks and telecommunication.
Hardware: The physical, tangible components of an ICT system.
Software: A set of programs and instructions that direct hardware to perform tasks.
Network: Two or more connected devices that share data and resources.

5. Step-by-step example

Worked example: tracing one WhatsApp photo through an ICT system

  1. Input: the phone camera captures the image and the touch screen records your tap on Send.
  2. Processing: the CPU compresses the photo from about 4 MB to about 200 KB so it travels faster.
  3. Storage: a copy is saved in the phone’s internal storage (local) and, if backup is on, in Google Drive (cloud).
  4. Communication: the Wi-Fi or 4G radio sends the data through the mobile network and the internet to WhatsApp’s servers.
  5. Output: your friend’s phone receives the data, decompresses it and displays it on the screen.

6. Pakistan-based examples

NADRA

NADRA’s database is one of the largest ICT systems in Pakistan: fingerprint scanners (input), central servers (processing and storage) and a national network let any registration centre verify a citizen in seconds.

Board result websites

When BISE Mirpur publishes Matric results, thousands of students open the same server at once. Slow loading on result day is a network bandwidth and server capacity problem, not a problem with the student’s phone.

7. Bhimber case study

Case study: setting up a 20-computer lab at a Bhimber school

A school in Bhimber receives 20 donated desktop computers. The principal wants students to practise MS Office, share one printer and use a single internet connection from a local provider. The ICT teacher plans a LAN: every computer connects with Ethernet cable to a switch, the switch connects to a router, and the router connects to the provider’s fibre line. One computer acts as the print host. Because electricity load-shedding is common, the teacher adds a UPS for the switch and router and tells students to save work every ten minutes and keep a copy on Google Drive.

Questions for analysis
  1. Which network type is this, and why?
  2. Identify two hardware items for each stage of the processing cycle in this lab.
  3. Why is cloud backup useful in an area with frequent power cuts?

8. Real-life applications

  • Schools: computer labs, digital attendance, online results.
  • Banks: ATMs, mobile banking, inter-branch WAN.
  • Hospitals: patient records, digital X-ray storage.
  • Government: NADRA, e-Khidmat centres, FBR online tax filing.
  • Homes: smart TVs, Wi-Fi routers, family photo backups.

9. Advantages and disadvantages

Advantages

  • Information can be processed and shared in seconds.
  • Resources such as printers and internet connections can be shared on a network.
  • Cloud storage makes files available on any device.
  • Digital records take less space and are easier to search than paper.

Disadvantages

  • Hardware is costly and needs electricity, which is unreliable in many areas.
  • Networks can be attacked by viruses and hackers.
  • Local storage can fail or be lost without a backup.
  • Dependence on technology can stop work during outages.

12. Important points for examination

  • Always give an example with each definition (for example, ‘Input device: keyboard’).
  • Know the difference between RAM (volatile) and storage (non-volatile).
  • LAN vs WAN is a favourite comparison question: cover area, ownership, speed and cost.
  • Remember the processing cycle in order: input, process, output, storage.

13. Lecture summary

  • ICT = information + communication + technology, wider than IT.
  • Every ICT system has hardware, software, networks and storage.
  • System software runs the machine; application software helps the user.
  • Networks are classified by area: PAN, LAN, MAN, WAN and the internet.
  • Local storage works offline; cloud storage works anywhere with internet.

14. Short questions

  1. Define ICT and give two examples from daily life.
  2. Differentiate between data and information with an example.
  3. Name two input and two output devices.
  4. What is the difference between system software and application software?
  5. Why is RAM called volatile memory?
  6. Write two advantages of cloud storage.

Long questions

  1. Explain the four components of an ICT system with suitable examples from a school computer lab.
  2. Compare LAN, MAN and WAN with respect to area, ownership, speed and examples.
  3. Discuss local storage and cloud storage. Which would you recommend for a student in Bhimber, and why?

16. Assignment

Prepare a two-page report titled ‘The ICT system in my home’. List every ICT device in your home, classify each as input, processing, output, storage or communication, name the operating system and three applications used on each main device, and draw a simple diagram of how the devices connect to the internet.

Homework

Find the storage capacity, RAM and operating system of your phone (Settings → About phone). Calculate roughly how many 3 MB photos could fit in its free space and write your working.

17. Suggested classroom discussion

  2. Is a smartphone a computer? Defend your answer using the processing cycle.
  3. Should schools keep student records on local servers or in the cloud?
