Discrete Structures · Lecture 10

Mathematical Induction

Week 4, slot 1 · CLO-2, CLO-3 · Bloom C3 · Prerequisite: Lectures 7–9 · Reference: Rosen 7th, Induction and Recursion

Home  /  BS CS  /  Discrete Structures  /  Lecture 10

Learning objectives

  1. State the principle of mathematical induction.
  2. Write a proof with a clear basis step, inductive hypothesis and inductive step.
  3. Prove summation formulas and divisibility statements by induction.
  4. Identify typical induction mistakes.

Roman Urdu. Mathematical induction se hum aisi statement sabit karte hain jo har natural number n ke liye ho. Do kaam karne hote hain: (1) pehla case sahih hai (basis step), (2) agar P(k) sahih ho to P(k+1) bhi sahih ho (inductive step). Domino ki misal: pehla domino girta hai aur har girne wala domino agle ko girata hai, to sab gir jate hain.

Core concepts

Principle of Mathematical Induction. Let P(n) be a statement about integers n ≥ n₀. If (1) Basis: P(n₀) is true, and (2) Inductive step: for every k ≥ n₀, P(k) → P(k + 1), then P(n) is true for all n ≥ n₀.

Template

Part What to write
Statement Define P(n) precisely
Basis Check P(n₀) directly
Hypothesis Assume P(k) for an arbitrary k ≥ n₀
Step Using P(k), prove P(k + 1)
Conclusion By induction, P(n) holds for all n ≥ n₀

Why it works. If P(n) failed for some n, there would be a smallest failing value m. Then m > n₀ and P(m − 1) is true, so the inductive step forces P(m) true, a contradiction. This uses the well-ordering of the natural numbers.

Misconceptions. Skipping the basis. Assuming P(k + 1) while proving it. Proving the step only for one particular k. Using the statement being proved in a circular way.

Worked examples

Example 1 (basic). Prove 1 + 2 + … + n = n(n + 1)/2 for n ≥ 1. Basis: n = 1 gives 1 = 1·2/2. True. Hypothesis: 1 + … + k = k(k + 1)/2. Step: 1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k/2 + 1) = (k + 1)(k + 2)/2, which is P(k + 1). ∎

Example 2 (intermediate). Prove 1 + 3 + 5 + … + (2n − 1) = n² for n ≥ 1. Basis: n = 1 gives 1 = 1². Step: assume the sum to (2k − 1) is k². Adding the next odd number 2k + 1 gives k² + 2k + 1 = (k + 1)². ∎

Example 3 (advanced). Prove 3 divides n³ − n for every integer n ≥ 1. Basis: 1³ − 1 = 0, divisible by 3. Hypothesis: k³ − k = 3m for an integer m. Step: (k + 1)³ − (k + 1) = k³ + 3k² + 3k + 1 − k − 1 = (k³ − k) + 3(k² + k) = 3m + 3(k² + k) = 3(m + k² + k). Divisible by 3. ∎

Example 4 (computing). Prove 1 + 2 + 4 + … + 2ⁿ = 2ⁿ⁺¹ − 1 for n ≥ 0. Basis: n = 0 gives 1 = 2¹ − 1. Step: assume the sum to 2ᵏ equals 2ᵏ⁺¹ − 1. Adding 2ᵏ⁺¹ gives 2ᵏ⁺¹ − 1 + 2ᵏ⁺¹ = 2·2ᵏ⁺¹ − 1 = 2ᵏ⁺² − 1. ∎ Meaning: the largest number storable in n + 1 bits is 2ⁿ⁺¹ − 1, and a full binary tree of height n has 2ⁿ⁺¹ − 1 nodes (Module 10).

Computer science connection

Correctness of recursive functions; analysing loop counts and running time; proving properties of data structures such as trees; the basis of recursive definitions used in programming.

Key takeaways

  • Induction needs a basis and an inductive step. Both are essential.
  • In the step, assume P(k) and prove P(k + 1).
  • Always state P(n) and the starting value n₀.

Roman Urdu. Induction mein pehle basis step check karte hain, phir maan lete hain P(k) sahih hai aur sabit karte hain P(k+1). Dono hissay zaroori hain. P(k+1) ko pehle se maan lena ghalti hai.

Five revision questions

  1. Write P(n) and the basis for "2ⁿ > n for all n ≥ 0."
  2. Prove 1² + 2² + … + n² = n(n + 1)(2n + 1)/6.
  3. Prove 2ⁿ > n for all n ≥ 0.
  4. What goes wrong if the basis step is omitted? Give an example.
  5. Explain the domino analogy in terms of basis and inductive step.

Homework. Prove by induction: (a) 2 + 4 + … + 2n = n(n + 1); (b) 5 divides 6ⁿ − 1 for n ≥ 1; (c) n! > 2ⁿ for n ≥ 4.

Induction ke do hisse?
