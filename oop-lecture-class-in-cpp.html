C++ me Class

Object-Oriented Programming in C++, explained in easy Roman Urdu.

Home  /  Programming  /  OOP Lectures  /  Lecture 7

Real life example

Class ghar ka naqsha hai, object bana hua ghar. public gate hai, private tijori.

Industry example

Game me Player class: health aur score private. takeDamage() public.

C++ code

class Player {
  int health = 100;   // private
public:
  void hit(){ health -= 10; }
};
Player p; p.hit();

What happens when it runs

p.hit() = health 90
p.health = Error: private
