Discrete Structures · Lecture 0

Discrete vs Continuous

Introduction · Before Week 1 · Why this course is called "Discrete"

Home  /  BS CS  /  Discrete Structures  /  Lecture 0

Is lecture ke baghair Discrete Structures samajh nahi aayega. Yahan hum sab se aasan tareeqe se samjhte hain ke discrete aur continuous mein kya farq hai, aur computer discrete kyun hai.

1. Discrete — matlab gina ja sakta hai

Discrete = countable, alag alag values.

Number of students in a class = 40. Class mein 40 students hain. 40.5 students nahi ho sakte — ya 40 honge ya 41, beech mein kuch nahi.

  • Tumhare paas kitne mobile hain? 1, 2, 3
  • Kitne bhai behan hain? 2, 3
  • Kitni books hain? 10, 15
  • Set of Integers: … −3, −2, −1, 0, 1, 2, 3 …

Number line par integers alag alag dots hote hain. Dots ka matlab hai values alag alag hain aur beech mein gap hai — 1 aur 2 ke beech mein koi integer nahi.

2. Continuous — matlab maapa ja sakta hai

Continuous = measurable, beech mein bhi values hain.

Heights of students = 5.5, 5.7 feet. Height 5.5 bhi ho sakti hai, 5.6 bhi, 5.65 bhi, 5.654 bhi. Beech mein be-shumaar values aa sakti hain.

  • Wazan: 60.5 kg, 60.55 kg
  • Temperature: 30.2 degree
  • Time: 12:30:45 second
  • Set of Real Numbers: −2.1, −2, −1, 0, 1, 1.1, 2 … number line par ek continuous line, koi gap nahi.

Easy yaad karne ka tareeqa

Discrete Continuous
Ginte hain Maapte hain
1, 2, 3 1.1, 1.2, 1.25
Students, books Height, weight, temperature
Set of Integers (ℤ) Set of Real Numbers (ℝ)

Trick: jawab ke liye "Kitne?" poocho to discrete hai. "Kitna?" poocho to continuous hai. Kitne students? → discrete. Kitni height? → continuous.

3. Digital devices vs analog devices

Yehi concept computer mein aata hai.

Digital devices — computer. Computer digits par kaam karta hai: 1 ya 0. Ya ON (1) ya OFF (0), beech mein kuch nahi. Isi liye computer discrete hai. Digital clock: seedha 12:30 batati hai, phir 12:30:01, phir 12:30:02 — ek ek kar ke jump karti hai.

Analog devices — continuous data. 0 aur 1 ke beech (interval (0, 1)) mein bhi sab kuch hai: 0.1, 0.2, 0.5, 0.9 … Analog clock: gol ghari ka kaanta ghoomta rehta hai, rukta nahi — 12 se 1 ke beech woh dheere dheere chalta hai. Yeh continuous hai.

Digital (discrete) Analog (continuous)
Mobile, laptop, calculator Purani ghari, thermometer, speedometer
Sirf 0 / 1 par chalte hain Sui (needle) wale, har value le sakte hain

Is course ka naam "Discrete" kyun hai?

Computer ke andar sab kuch discrete hai — bits, integers, lists, graphs aur trees. Isi liye Computer Science ko discrete mathematics ki zaroorat hoti hai: logic, proofs, sets, relations, functions, counting, graphs aur trees. Agle lectures mein hum yehi seekhenge, shuruaat logic se.

Exam mein kya aayega?

Q1. Discrete aur continuous mein farq batao, 2 examples ke saath. Answer: upar wali table likh do — discrete: students, books (ginte hain); continuous: height, weight (maapte hain).

Q2. Computer digital hai ya analog? Kyun? Answer: Digital, kyun ke woh sirf 0 aur 1 par kaam karta hai, jo discrete values hain.

Q3. Set of Integers discrete hai ya continuous? Answer: Discrete, kyun ke us ki values alag alag (dots) hain aur beech mein gap hai.

Quick check

  1. Class mein bachon ki tadaad — discrete ya continuous?
  2. Petrol tank mein petrol ki miqdar — discrete ya continuous?
  3. Speedometer digital device hai ya analog?
  4. Set of Real Numbers number line par dots hain ya continuous line?
