Frequently asked questions

Is this C++ course free?

Yes. All 12 lectures, quizzes and the online compiler are free.

Do I need to install a compiler?

No. Run your C++ code in the online compiler on this page.

Who is this course for?

Beginners and university students studying PF, OOP and Database Systems.

Can I practise SQL without installing anything?

Yes. Database Level 1 has a small SQL engine inside the page, so you can run SELECT, INSERT, UPDATE, DELETE and JOIN in your browser.
